# Muliro && Associate — Insurance Intermediary Website

A modern React + Vite website for an insurance intermediary, built with Tailwind CSS and Radix UI primitives. The app includes marketing pages, product presentation, and a responsive lead-generation layout.

## Features

- Multi-page navigation with `react-router`
- Responsive design for desktop and mobile
- Pages for Home, About, Products, Product Details, Partners, Quote, Contact, Blog, and FAQ
- Theme-aware visuals using `next-themes`
- Accessible UI components and interactions
- Ready for content and media updates

## Tech stack

- Vite
- React
- TypeScript
- Tailwind CSS
- Radix UI primitives
- Material UI icons
- React Router
- Sonner notifications
- Recharts charts
- Framer Motion animations

## Getting started

```bash
pnpm install
pnpm run dev
```

Open the local development URL shown in the terminal, usually `http://localhost:4173`.

## Available scripts

- `pnpm run dev` — start the development server
- `pnpm run build` — build the production bundle

## Project structure

- `src/main.tsx` — application entry point
- `src/app/App.tsx` — router and app wrapper
- `src/app/routes.tsx` — route definitions
- `src/app/components` — shared UI components and layout
- `src/app/pages` — individual page views
- `src/app/contexts` — app context providers
- `src/styles` — global styles and Tailwind configuration

## Notes

- This repository is configured for `pnpm`, but you can also use `npm` if needed.
- Make sure you have a current Node.js version and support for ES modules.
